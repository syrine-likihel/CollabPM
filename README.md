# 🚀 CollabPM

A Full Stack collaborative project management platform developed using **Spring Boot** and **Angular**.

CollabPM helps teams efficiently manage projects, tasks, members, and collaboration through a modern web application with a clean architecture and RESTful APIs.

> **Status:** 🚧 Currently under development (Academic Project)

---

## 📌 Features

### 👤 User Management
- User authentication *(In Progress)*
- User role management
- Profile management

### 📁 Project Management
- Create, update, delete and view projects
- Project details
- Project status management

### ✅ Task Management
- CRUD operations for tasks
- Task assignment
- Task priorities
- Task status updates
- Due dates

### 👥 Team Management
- Add members to projects
- Assign tasks to members
- Team collaboration

### 💬 Comments
- Add comments to tasks
- View task discussions

### 📊 Dashboard
- Project statistics
- Task statistics
- Progress overview

### 📋 Kanban Board
- Drag & Drop task workflow
- Status management
- Task organization

### 🔧 Backend Features
- RESTful APIs
- Layered Architecture
- DTO Pattern
- Mapper Pattern
- Validation
- Exception Handling
- Spring Data JPA
- Hibernate ORM

### 🧪 API Testing
- Postman Collection

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/syrine-likihel/CollabPM.git
```

---

## Backend

```bash
cd "CollabPM backend"
mvn spring-boot:run
```

---

## Frontend

```bash
cd collabpm-frontend
npm install
ng serve
```

Open your browser:

```
http://localhost:4200
```
